# Fases de desarrollo (metodología)
Fase 1 – Núcleo de datos y seguridad: modelos de BD, hashing, cifrado base [X]
Fase 2 – Autenticación: registro/login con validaciones y verificación de correo [X]
Fase 3 – Perfil y catálogo de intereses/facultades [X]
Fase 4 – Motor de búsqueda/matching 
Fase 5 – Chat (primero local/simulado, luego con sockets reales)
Fase 6 – Integración GUI completa
Fase 7 – Pruebas de seguridad (pentesting básico, pruebas unitarias)

# FUNCIONAMIENTO DEL ALGORITMO DE BUSQUEDA
Se usa el **índice de Jaccard** o **coeficiente de similitud** como algoritmo para hacer las conexiones entre los estudiantes. 

Si quieres conocer más acerca del índice de Jaccard [click aqui](https://www.statisticshowto.com/jaccard-index/)
